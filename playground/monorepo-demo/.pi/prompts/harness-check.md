# Harness Check（使用检查）

检查当前项目的 Harness 是否**真正被当前 AI 使用**，而不只是「文件存在」。不静默修改任何规则。

## 步骤

1. 检查 AGENTS.md 工作规范、`.pi/`（agents/prompts/settings.json/extensions）、`.claude/`、`.harness/` 状态。
2. 对照最近真实任务：是否建立 Session、选择 Skill、AI 是否读取了被选 Skill、是否记录了文件变化、验证和交付结果。
3. 把「缺失 / 已配置 / 已接入 / 已执行 / 结果已证明」分开，**不要用配置存在冒充实际使用**。
4. 对每个断点给出最小修复载体（规则、Skill、脚本、Hook、宿主适配或人工门禁）、验收、回滚和下一步中文提示词。
5. 生成 `.harness/generated/harness-check.md`；不静默修改任何规则。

## 检查维度

| 维度 | 证据 | 状态 |
|---|---|---|
| 规则接入 | AGENTS.md 工作规范被读取 | 缺失/已配置/已接入 |
| 角色 | `.pi/agents/` 被流水线调用 | 缺失/已配置/已接入 |
| Skill | 被选 Skill 被实际读取用于任务 | 缺失/已配置/已接入 |
| 证据 | 文件变化/验证/交付写入 `.harness/` | 缺失/已配置/已执行 |
| 结果 | 有阶段产物与交付结论 | 缺失/已配置/已证明 |

## 输出

`.harness/generated/harness-check.md`：每个断点的问题、最小修复载体、验收、回滚、下一步提示词。

## 安全约定

- 不静默修改规则；候选修复需经审核。
- 不读取/打印/提交秘密。
