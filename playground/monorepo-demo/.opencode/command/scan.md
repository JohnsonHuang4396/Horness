# Scan（重新扫描项目）

对当前项目做一次**只读**重新扫描，更新 `.harness/generated/scan-candidate.md` 与项目 profile。不修改业务代码或正式规则。

## 步骤

1. 以锁文件、构建描述、入口源码为准，识别语言/框架/版本/包管理器/源码根/测试入口/构建命令/生成目录。
2. 更新 `.harness/generated/scan-candidate.md`：事实、推断、冲突、未知项分列。
3. 对比上次扫描，输出差异（新增/变更/失效的假设）。
4. 更新建议启用的 Skill 及证据、排除的 Skill 及原因。

## 安全约定

默认只读本地文件，不联网；不读取/打印/提交秘密；不覆盖已有文件；差异声明，不静默修改规则。
