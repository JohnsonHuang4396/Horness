# 数据库工程能力

## 触发与边界

只有发现数据库驱动、迁移目录、DDL、Mapper/JPA/SQL 或数据脚本且任务涉及数据时加载。先确认数据库类型、版本、迁移工具、部署顺序和备份能力。

## 必须检查

- 追踪表/字段/索引/约束到读写代码、DTO、缓存、报表、消息和回填脚本。
- 设计扩展优先的兼容迁移：先加后用、双读/双写、回填、切换、再删除；记录锁、超时、批量大小和在线窗口。
- 对 SQL 做参数化、权限、NULL/时区/排序/分页、索引和 EXPLAIN 检查，避免 N+1 与全表锁。
- 明确失败回滚、备份恢复和半完成迁移处理；绝不在未知环境直接执行破坏性 SQL。

## 验证

先静态校验脚本与迁移顺序，再在项目提供的隔离数据库/CI 中验证；无数据库环境时只报告未观察，不伪称通过。

详细检查清单见 `references/stack-pack.md` 与 `references/verification.md`。
