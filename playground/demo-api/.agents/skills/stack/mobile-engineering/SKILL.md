# 移动端工程能力

## 触发与边界

先确认平台、语言、构建工具、最低系统版本和目标设备。不得凭 H5/前端关键词激活，也不得在没有签名/发布审批时执行上传。

## 必须检查

- 追踪页面/组件、状态、网络、缓存、原生桥、权限、深链、推送、后台任务和崩溃上报。
- 核对 API 兼容、弱网/离线、生命周期、旋转/多窗口、权限拒绝、低端设备和无障碍。
- 检查构建变体、证书/签名键名、依赖、资源、混淆、商店元数据和回滚版本；秘密只验证存在性，不读取值。

## 验证与回退

优先运行项目 wrapper 的静态检查、单元测试、打包和设备/模拟器验证；缺少设备时清楚标记未观察。失败保留构建日志和可安装的上一版本。

详细检查清单见 `references/stack-pack.md` 与 `references/verification.md`。
