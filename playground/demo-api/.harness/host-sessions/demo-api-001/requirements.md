# P1 需求基线（Requirements）

- **目标**：`GET /health` 返回 `200` + `{"status":"ok"}`
- **范围**
  - 包含：`/health` 路由；未知路径维持 404
  - 不包含：鉴权、数据库探活、指标
- **需求表**
  | ID | 需求 | 来源 | 验收条件 |
  |---|---|---|---|
  | REQ-1 | `/health` 返回 200 + ok | 用户原话 | AC-1.1 |
  | REQ-2 | 未知路径仍 404 | 推断 | AC-2.1 |
- **必须保持的契约**：`node:http` 服务可独立启动
- **假设**：fetch 可用（Node 24）
- **未决问题**：无
