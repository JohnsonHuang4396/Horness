# P3 方案设计（Design）

- **现状**：server 只有 404 兜底，无健康检查
- **设计约束**：零外部依赖；`createServer` 可注入 handler 便于测试
- **方案对比**
  | 方案 | 优点 | 缺点 | 结论 |
  |---|---|---|---|
  | A 直接 listen 后改 | 直观 | 不可测 | 备选 |
  | B 导出 `handler` + 测试注入 | 真实验证 | 多一个导出 | 选定 |
- **选定方案**
  - 模块：`handler(req,res)` 纯函数 + `server` 导出
  - 路由：`/health` → 200 JSON；其余 → 404
  - 错误处理：URL 解析回退 `/`
- **追踪矩阵**：REQ-1→`/health` 分支；REQ-2→兜底分支
- **决策与剩余风险**：无
