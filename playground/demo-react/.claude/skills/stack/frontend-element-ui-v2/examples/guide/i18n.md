# Internationalization / 国际化

**官方文档**: https://element.eleme.cn/2.15/#/zh-CN/component/i18n

## Instructions

This example demonstrates how to configure internationalization (i18n) in Element UI 2.x.

### Key Concepts

- Built-in locale support
- Switching locale at runtime
- Integration with vue-i18n
- Custom locale messages

### Example: Using Built-in Locale (Chinese)

```javascript
// main.js
import Vue from 'vue'
import ElementUI from 'element-ui'
import locale from 'element-ui/lib/locale/lang/zh-CN'
import 'element-ui/lib/theme-chalk/index.css'
import App from './App.vue'

Vue.use(ElementUI, { locale })

new Vue({
  el: '#app',
  render: h => h(App)
})
```

### Example: Integration with vue-i18n 5.x

```javascript
import Vue from 'vue'
import VueI18n from 'vue-i18n'
import ElementUI from 'element-ui'
import enLocale from 'element-ui/lib/locale/lang/en'
import zhLocale from 'element-ui/lib/locale/lang/zh-CN'

Vue.use(VueI18n)
Vue.use(ElementUI)

const messages = {
  en: {
    message: 'hello',
    ...enLocale
  },
  zh: {
    message: '你好',
    ...zhLocale
  }
}

const i18n = new VueI18n({
  locale: 'zh',
  messages
})

new Vue({
  i18n,
  render: h => h(App)
}).$mount('#app')
```

### Example: Integration with vue-i18n 6.x+

```javascript
import Vue from 'vue'
import VueI18n from 'vue-i18n'
import ElementUI from 'element-ui'
import ElementLocale from 'element-ui/lib/locale'
import enLocale from 'element-ui/lib/locale/lang/en'
import zhLocale from 'element-ui/lib/locale/lang/zh-CN'

Vue.use(VueI18n)
Vue.use(ElementUI)

const messages = {
  en: { ...enLocale },
  zh: { ...zhLocale }
}

const i18n = new VueI18n({
  locale: 'zh',
  messages
})

ElementLocale.i18n((key, value) => i18n.t(key, value))
```

### Example: Dynamically Switch Locale

```vue
<template>
  <div>
    <el-button @click="switchLang('zh')">中文</el-button>
    <el-button @click="switchLang('en')">English</el-button>
    <el-date-picker v-model="date" type="date" />
  </div>
</template>

<script>
import ElementLocale from 'element-ui/lib/locale'
import zhLocale from 'element-ui/lib/locale/lang/zh-CN'
import enLocale from 'element-ui/lib/locale/lang/en'

export default {
  data() {
    return {
      date: ''
    }
  },
  methods: {
    switchLang(lang) {
      const localeMap = {
        zh: zhLocale,
        en: enLocale
      }
      ElementLocale.use(localeMap[lang])
    }
  }
}
</script>
```

### Available Locales

Element UI 2.x supports 50+ languages, including:
- `zh-CN` - 简体中文
- `zh-TW` - 繁體中文
- `en` - English
- `ja` - 日本語
- `ko` - 한국어
- `fr` - Français
- `de` - Deutsch
- `es` - Español
- `ru` - Русский

All locale files are in: `element-ui/lib/locale/lang/`

### Key Points

- Default locale is Chinese (zh-CN)
- Pass `locale` option to `Vue.use(ElementUI, { locale })`
- For vue-i18n 6.x+, use `ElementLocale.i18n()` to bridge
- Locale affects: DatePicker, Pagination, Dialog buttons, etc.
- Can switch locale dynamically using `ElementLocale.use()`
