# Doctor（Harness 体检）

检查 Harness 是否真正支撑任务理解、可控执行、改动验证、可靠交付和经验沉淀，**不把文件存在当作有效使用**。加载 `harness-doctor` 技能执行。

## 检查维度

1. **任务理解**：是否登记 Session、写 intake、判定任务类型与模式。
2. **可控执行**：是否走 P0-P10 阶段门禁、有失败回退、不擅自扩大范围。
3. **改动验证**：是否对每个批次做窄验证、有验证命令与退出码证据。
4. **可靠交付**：是否产出阶段产物、验收矩阵、回滚路径。
5. **经验沉淀**：是否写 summary/run-report、生成可审批候选。

## 输出

`.harness/generated/doctor-report.md`：按维度列出证据、缺失项、修复建议（最小载体）、验收与回滚。每个发现引用真实文件路径与证据，不虚构。

## 安全约定

- 只读检查，不修改业务代码或正式规则；候选修复需经审核。
- 不读取/打印/提交秘密。
