# P1 需求基线（Requirements）

- **目标**：App 显示一个计数器，`+`/`-` 按钮增减，初值 0
- **范围**
  - 包含：`<button>+/-</button>` + 计数显示；counter 逻辑抽成纯函数
  - 不包含：异步、持久化、样式美化
- **需求表**
  | ID | 需求 | 来源 | 验收条件 |
  |---|---|---|---|
  | REQ-1 | 初值 0，可增减 | 用户原话 | AC-1.1, AC-1.2 |
  | REQ-2 | 计数逻辑可独立验证（纯函数） | 推断 | AC-2.1 |
- **必须保持的契约**：App 仍由 main.tsx 挂载
- **假设**：React 18 + useState
- **未决问题**：无
